# Chetan Patil — Portfolio

A responsive personal portfolio for a software engineer focused on .NET, C#, ASP.NET Core, Angular, and SQL Server.

## Live site

Published through GitHub Pages: https://chetan1237.github.io/

## Built with

- Semantic HTML
- CSS (responsive layout, no CSS framework)
- Vanilla JavaScript
- Google Fonts (Manrope and DM Mono)

## Structure

- `index.html` — portfolio content and page structure
- `assets/css/style.css` — visual system and responsive styles
- `assets/js/main.js` — mobile navigation and current year

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Deployment

The repository uses GitHub Pages. The root `index.html` is the site entry point.

## Content accuracy

The portfolio describes areas of experience and current learning focus without presenting incomplete or unverified repositories as finished products. Update project case studies only when their source code, functionality, and screenshots have been verified.
